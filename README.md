# 💰 Personal Expense Tracker

A simple web-based Personal Expense Tracker developed using **Python, Flask, SQLite3, HTML, and CSS**. This application helps users manage daily expenses by allowing them to add, view, edit, and delete expense records.

---

## 📌 Features

- ➕ Add new expenses
- 📋 View all expenses
- ✏️ Edit existing expenses
- ❌ Delete expenses
- 💾 Store data using SQLite3
- 🎨 Simple and user-friendly interface

---

## 🛠️ Technologies Used

- Python
- Flask
- SQLite3
- HTML5
- CSS3

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/SaiHimaSindhu/Personal-Expense-Tracker.git
```

### 2. Move to the project folder

```bash
cd Personal-Expense-Tracker
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open your browser

```
http://127.0.0.1:5000
```

## 💾 Database

This project uses **SQLite3** as the database.

The database stores:
- Expense ID
- Category
- Amount
- Date
- Description
